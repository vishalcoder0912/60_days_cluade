# Day 16 - Build Your First Stock Research Skill

## Challenge

**Claude Custom Skills – Day 16**

### Objective

Learn how to create reusable AI workflows using Claude Custom Skills and build a structured stock fundamental research assistant that can analyze Indian and global listed companies using publicly available financial data.

---

# Custom Skill Information

## Skill Name

`stock-fundamental-research`

## Description

Analyze Indian and global listed companies using fundamentals, financial statements, business quality, competitive advantages, valuation, risks, ownership trends, and growth prospects.

Generate evidence-based research reports and investor-friendly summaries without providing buy/sell recommendations.

---

# Why This Skill Matters

Normally, every stock analysis requires writing long prompts repeatedly.

Using Claude Custom Skills allows us to:

* Save complex workflows permanently
* Reuse the same research framework
* Generate consistent reports
* Improve productivity
* Reduce repetitive prompting

# Key Learnings

### 1. Context Creates Better Results

The quality of outputs improves significantly when Claude is given a structured research framework.

### 2. Reusable Workflows Save Time

Custom Skills eliminate the need to repeatedly paste long prompts.

### 3. AI Can Organize Complex Research

Claude can transform scattered financial information into structured reports.

### 4. Evidence-Based Analysis Matters

The skill emphasizes factual analysis rather than speculation.

### 5. Productivity Multiplies with Custom Skills

One well-designed skill can be reused indefinitely across multiple stocks and industries.
